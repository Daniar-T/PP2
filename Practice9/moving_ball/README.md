# Moving Ball

A simple interactive game built with Python and Pygame. Move a red ball around a white window using the arrow keys.

## Features

- Displays a red ball with a radius of 25 pixels
- Moves the ball 20 pixels with each arrow-key press
- Prevents the ball from moving outside the window

## Controls

- `Up Arrow` — move up
- `Down Arrow` — move down
- `Left Arrow` — move left
- `Right Arrow` — move right
- Close the window to quit

## Requirements

- Python 3
- Pygame Community Edition (`pygame-ce`)
