# Mickey's Clock

A clock built with Python and Pygame. It uses hand graphics to display the current minutes and seconds.

## Features

- Displays the current system time
- The right hand shows the minutes
- The left hand shows the seconds
- Updates in real time

## Requirements

- Python 3
- Pygame Community Edition (`pygame-ce`)

From the repository root, activate the virtual environment:
