# Music Player

A simple music player built with Python and Pygame.

## Features

- Play and stop tracks
- Skip to the next or previous track
- Display the current track name and playback position
- Load `.wav` and `.mp3` files from the `music` folder

## Controls

- `P` — play
- `S` — stop
- `N` — next track
- `B` — previous track
- `Q` — quit

## Requirements

- Python 3
- Pygame Community Edition (`pygame-ce`)
